# Rainroom

An atmospheric weather website with live city search, animated weather backgrounds, and interactive pixel characters.

## Run locally

No build or dependencies required. Serve this directory with any static web server, for example:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000.

## Files

- `index.html`: layout and styles
- `app.js`: Open-Meteo forecasts, city search, and weather themes
- `characters.js`: original interactive pixel characters

Forecasts use Open-Meteo. Google Fonts supplies the optional web fonts. Both require an internet connection.

Live site: https://rainroom-weather-nov13.chalkyseahorse8.chatgpt.site
